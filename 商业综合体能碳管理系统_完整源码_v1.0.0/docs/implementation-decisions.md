## 2026-08-14 三模块决策

- 公共能耗只从 `merchant_id is null` 且具有公共区域/公共层级语义的节点读取；商户直计只从 `merchant_id is not null` 读取，以集合互斥防止重复。
- 原始能源量坚持按能源类型展示，仅费用、tce 和碳排放允许跨能源汇总。
- 账单采用追加版本而非覆盖：重生成将旧版本 `current_version_flag` 置 0，并写入新版本；完整率不足或高风险问题未闭环时不允许确认。
- 手工比例存入 `energy_allocation_rule.parameters_json`，合同默认比例继续复用 `merchant_occupancy.shared_energy_ratio`。
- 能源修正不另写碳核算算法，更新能耗记录后依赖原数据库触发器重算；质量复核表保存前后 JSON 快照。
- 月报保持动态生成，避免引入可能与实时数据不一致的报告快照表；打印采用浏览器原生 PDF 能力。
