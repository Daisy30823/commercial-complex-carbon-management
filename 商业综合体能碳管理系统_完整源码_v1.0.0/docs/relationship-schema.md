## 核心关联关系

商业综合体关联建筑、部门、商户、计量节点、预算、预警规则和节能项目；建筑关联功能区域；商户通过入驻关系关联区域；计量节点通过 `parent_node_id` 自关联形成树；计量设备产生能源消费记录，数据库触发器据此生成碳核算记录；预警事件关联整改任务；节能项目关联效果评价。
