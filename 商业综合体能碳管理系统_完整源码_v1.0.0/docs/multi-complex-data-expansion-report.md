## 数据规律与口径

- 每个正式综合体生成最近 180 天、至少 3 个完整自然月的日度记录。
- 综合体规模系数分别为 0.97、1.04、1.11、1.18，仅对程序生成记录应用一次，并写入原始 JSON 防止重复缩放。
- 不同能源原始单位不相加；综合能耗使用 `energy_type.standard_coal_coefficient` 换算为 tce。
- 能耗记录通过原有触发器生成或更新碳核算记录，最终 27,102 对 27,102，无缺失。
- 每个年度预算覆盖全部启用区域的 12 个月，预算完整性缺口为 0；实际排放由 `sp_refresh_budget_actuals` 刷新。
- 商户账单由 `sp_generate_merchant_energy_bills` 生成，最近 3 个完整月的数据完整率为 100%。
- 质量问题由 `sp_scan_data_quality_issues` 的突增、待审核、异常标记等规则扫描生成，指纹防止重复开放问题。
