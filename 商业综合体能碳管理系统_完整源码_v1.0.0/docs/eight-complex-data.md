# 八综合体业务数据说明

## 数据脚本

- `database/patches/051_expand_to_eight_complexes.sql`：幂等新增温州、金华、湖州、台州四个正式综合体。
- `database/patches/052_generate_four_new_complex_business_data.sql`：基于现有数据库对象和触发器生成四个综合体的完整业务链数据。

脚本不重新执行主 SQL，不删除既有记录，不修改表结构。编码前缀分别为 `wz`、`jh`、`hu`、`tz`，业务规模系数不同，使能耗和费用结果存在合理差异。
