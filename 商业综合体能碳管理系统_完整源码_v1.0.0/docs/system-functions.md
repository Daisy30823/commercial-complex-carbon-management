# 系统功能说明

## 业务主线

系统以商业综合体为数据边界，完成建筑、区域和商户建档；通过分级计量节点和计量设备采集能源消费；由 MySQL 触发器自动生成碳核算；再结合预算、预警、整改和节能项目形成运营闭环。

## 功能模块

1. **认证与权限**：管理员登录、普通用户注册、Session 校验、角色权限、退出登录、个人中心和 BCrypt 修改密码。
2. **综合体与空间**：综合体、建筑、功能区域、物业部门和多综合体上下文切换。
3. **商户运营**：商户档案、入驻区域、经营状态和商户能碳摘要。
4. **分级计量体系**：`meter_node.parent_node_id` 自关联树、根节点/子节点新增、编辑、停用和循环校验。
5. **计量设备**：设备档案、能源类型、在线状态、最后采集时间和节点归属。
6. **能源消费**：日期、设备、区域、能源类型筛选；JSON 原始报文、异常、审核、新增和修正。
7. **碳核算**：排放因子、因子快照、活动数据、核算公式、kgCO₂e/tCO₂e 展示。
8. **碳预算**：年度预算、月度区域明细、实际值刷新、剩余额、执行率和超预算查询。
9. **预警整改**：预警规则、事件、确认、责任分配、整改、复核和关闭。
10. **节能项目**：项目投资、实施状态、节能量、减排量、节能率、投资回报率和回收期。
11. **商户能碳账单**：公共能耗分摊、月度账单、能源明细、确认和 CSV 导出。
12. **月度报告**：按综合体和月份生成能碳汇总、结构、趋势及质量说明。
13. **数据质量中心**：规则扫描、问题列表、复核、修正和扫描日志。
14. **专题查询**：七个 MySQL 查询存储过程的中文条件表格和 CSV 导出。
15. **审计与个人中心**：操作日志查询、JSON 查看、资料修改和最近操作。

## 数据可视化

总览驾驶舱包含六种 ECharts 图表：时间趋势折线图、区域排放横向柱状图、能源结构环形图、日期与区域热力图、区域绩效雷达图和年度预算半圆仪表盘。全部数据通过 Java API 查询 MySQL，并支持综合体与统计日期筛选。

## 课程设计声明

系统中的能源、成本、排放、预算、预警和项目数据均为程序生成的课程示例数据。核算结果仅用于教学和系统演示，不构成正式碳核证结论。
