# 更新日志

## v1.0.1 - 2026-08-15

- 增加 Railway Docker 多阶段构建、私网 MySQL 连接和固定根路径部署。
- 增加一次性云数据库基线、迁移历史保护和环境变量管理员初始化。
- 增加数据库健康检查、注册限流和生产 Session Cookie 安全配置。
- 增加 GitHub Actions、公开仓库文档、许可证与安全策略。

本项目采用语义化版本号。当前版本冻结后，除修复构建或交付阻塞错误外，不再修改核心业务功能和数据库设计。
