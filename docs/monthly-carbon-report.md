# 月度能碳报告

入口为 `#/monthly-reports`。报告通过 `sp_generate_monthly_carbon_report_dataset`、月度区域/商户/能源结构/项目过程和账单查询动态组合，不使用前端固定数据。

章节包括报告基本信息、覆盖范围和完整率、执行摘要、能源结构、区域能碳表现、高排放商户、商户账单、预算与预警整改、节能项目、数据质量和规则化管理建议。覆盖日期小于当月天数时，报告顶部显示当前采集日期、实际/应有记录数，并明确“部分指标仅代表已覆盖时段”；存在高风险质量问题时显示数据质量风险提示。

报告使用原始能源单位分项，综合能源使用 `standard_coal_coefficient` 换算 tce，碳排放统一 kgCO₂e/tCO₂e，金额统一人民币元。打印按钮使用专用 print CSS 和 `window.print()`，浏览器可选择另存为 PDF；导出按钮生成 UTF-8 BOM CSV。

报告和项目、预算、质量结果均为课程设计模拟管理数据，不代表正式碳核证、碳交易资产或法定排放报告。
