# 表格排序设计

## 接口参数

分页列表支持：

- `sortBy`：排序字段，只接受当前资源白名单中的字段。
- `sortOrder`：`asc` 或 `desc`。

非法列名或排序方向返回 400。后端绝不把用户传入的字段名直接拼接到 SQL。

## 后端实现

`SqlSortHelper` 为每个资源声明字段到真实列的固定映射和默认顺序：

- 综合体、建筑、区域、商户、计量节点、设备；
- 能耗、碳核算、预算、预警、整改、项目、评价；
- 用户、角色、操作日志；
- 商户账单和数据质量问题。

分页资源在 MySQL 查询中排序后再执行 `limit/offset`。数据质量中心使用带表别名的专用白名单。商户账单由存储过程返回完整结果后，在 Java 服务层按白名单稳定排序。专题查询一次返回完整结果集，按需求允许在浏览器完整集合上排序。

## 前端交互

统一脚本：`src/main/webapp/assets/js/table-sort.js`。

- 首次点击列头按降序，再次点击切换升序；
- 显示 `↕`、`↓`、`↑` 状态；
- 支持鼠标、Enter 和 Space；
- 使用 `aria-sort` 表达无排序、升序和降序；
- 各模块排序状态保存在 `sessionStorage`；
- 切页、筛选和 CSV 导出沿用当前排序；
- 点击重置同时清除当前模块排序。

## 索引结论

执行 `explain` 后，能耗设备日期、数据质量综合过滤、商户账单年月状态均使用已有索引（含上一轮 `044_multi_complex_indexes.sql`）；排序只对过滤后的可控结果集使用 filesort。本轮未创建 `053`，避免为多个可选排序列增加重复或低收益索引。
