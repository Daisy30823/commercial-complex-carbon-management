# 课程提交说明

项目名称：《商业综合体能耗与碳排放数智管理系统的设计与实现》  
正式版本：`v1.0.0`

## 推荐检查顺序

1. 阅读 `README_提交说明.md` 和 `04_设计文档/系统功能说明.md`。
2. 查看 `04_设计文档/E-R图.png`、关系模式和数据表结构说明。
3. 使用 `02_数据库/一键初始化数据库.bat` 在全新 MySQL 8 环境初始化。
4. 配置 `03_部署包/db.properties`，运行 `一键启动系统.bat`。
5. 登录后依次检查六类 CRUD、分级计量体系、能源与碳核算、预算、预警整改、节能项目和六类图表。

## 环境与账号

- Java 17、MySQL 8、Tomcat 10.1。
- 访问地址：`http://localhost:8080/commercial-complex-carbon/`。
- 本地管理员凭据仅保存在部署者私有配置中，不随提交包公开。
- 发布或公网使用前必须修改默认密码；MySQL 密码由检查者在本地配置，不包含在提交包中。

## 三种材料

- `01_完整源码`：用于源码、Maven、Java、JSP、JavaScript、SQL 和文档审查。
- `02_数据库`：包含原始 SQL、固定顺序补丁、完整演示数据库和验证脚本。
- `03_部署包`：包含无密码 WAR、配置示例和 Windows 一键脚本。

## 数据声明

所有能耗、碳排放、预算、预警、整改和节能项目数据均为程序生成的课程示例数据。系统核算结果不构成正式碳核证结论，也不得作为可交易碳资产依据。当前提交包不包含公网地址，也未上传 GitHub。
